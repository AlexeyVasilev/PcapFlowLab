# Historical Technical Documentation

These documents preserve design rationale, migration records, audits,
investigations, and superseded plans from earlier Pcap Flow Lab development
stages.

They are retained intentionally because they explain how the current
architecture evolved.

They are not authoritative for current Pcap Flow Lab behavior.

Current technical documentation starts at
[`../README.md`](../README.md).

History folders:

- `rfc/`
  Implemented design RFCs and architectural rationale.
- `design/`
  Design/evolution documents and superseded branch-era architecture notes.
- `audits/`
  Dated parity and readiness audits.
- `investigations/`
  Performance, memory, and implementation investigations.
- `plans/`
  Superseded working plans and historical testing plans.
